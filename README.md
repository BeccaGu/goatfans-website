# GOATFANS Website

A simple multi-page static website designed to be easy to maintain and deploy on Vercel.

## Pages
- `/` — Homepage + Services
- `/work/` — Work / Case Studies / News
- `/youtube/` — GOATFANS YouTube
- `/about/` — About / Chris Rong / Blog
- `/playlist/` — GOATFANS Radio / Apple Music
- `/contact/` — Contact

## Easiest way to edit
Open the relevant `index.html` file and search for the text you want to change.
Shared visual styles live in `assets/css/style.css`.
Images go in `assets/images/`.

## Apple Music
Open `playlist/index.html`, search `APPLE_MUSIC_PLAYLIST_URL`, and replace the placeholder section once you have your Apple Music embed URL.

## Deploy
Upload the contents of this folder to the root of your GitHub repository, then import that repository into Vercel. No build command is needed for this static site.
